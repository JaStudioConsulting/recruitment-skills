# Security and privacy

Do not commit credentials, environment files, candidate records, resumes, transcripts, reference checks, client material, or generated outputs.

Report a suspected exposure privately to the repository owner. Do not open a public issue containing the sensitive material. Revoke or rotate exposed credentials in their owning system, then remove the material through the approved repository remediation process.

This package contains policy and sanitized fixtures only. Integrations, account identifiers, staff addresses, credentials, and output locations belong to the consuming host or gateway.
