# candidate-defense

Defense-first candidate advocacy for Top Tier Talent Group.

**Use this when the goal is to advocate**, not just assess. Vet is for go/no-go screens.
Candidate-defense is for reframing, overcoming objections, and making the case.

One mode at a time. **Stop after each mode. Do not proceed unless Ja asks.**

---

## Mode Detection

Read what Ja said and infer intent. Do not require exact phrases.

| Intent | Mode |
|---|---|
| Wants the case built / objection overcome / candidate defended | MODE 1 — Defense Brief |
| Wants the submission email written (defense framing) | MODE 2 — Submission Email |
| Wants the resume reframed (rewording only, no new facts) | MODE 3 — Resume Reframe |
| Wants everything | Full Package — run 1 → 2 → 3, pause between each |

If intent is genuinely unclear after reading the message, ask one question only:
**"Defense brief first, or do you want the full submission package?"**

Do not ask if context already makes it obvious.

---

## Before Any Mode Runs

Check what inputs are present:

- **Resume provided?** Required for all modes. If missing, ask for it before doing anything.
- **JD provided?** Required for Mode 1 and Mode 2. If missing, ask: "Do you have a JD or role brief? I need it to build the defense."
- **Call notes provided?** Optional but strongly preferred for Mode 1. The defense is strongest with what the candidate actually said. If missing, ask: "Do you have call notes? They help me build a stronger case."
- **Objection stated?** If Ja explicitly named the objection (e.g. "his title will get him rejected"), capture it and center the defense around it. If not stated, infer the likely objection from the resume-vs-JD gap.

Do not start a mode until the required inputs are present.

---

## Hard Rules (All Modes)

- **Never fabricate titles, scope, comp, credentials, tools, metrics, or achievements.** Every claim must trace to the resume, JD, or call notes.
- **Never invent a number.** If the candidate said "improved efficiency" with no percentage, do not add one.
- **Honest caveats are allowed and encouraged** — Ja's style surfaces gaps plainly (see [`ja-style.md`](../ja-writer/references/ja-style.md): "surfaces caveats plainly; quotes the candidate's own words").
- **Suggested resume rewording** must be grounded in what the resume already says — tighten clarity, never add new facts.
- **If the case cannot be made honestly, say so.** Do not force a defense.
- **Bold labels before the colon, and key proof points inside bullets only.** Do not bold full sentences.
- **Canadian spelling** (labour, centre, defence, behaviour — follow Canadian).
- Only include field lines that have confirmed data — skip lines with nothing to say.

## MODE 1 — Defense Brief

Read resume + JD + call notes. Identify the anticipated objection, then build the case.

### Section 1 — The Objection

State what will hurt the candidate on paper:

> **Likely Objection:** [One sentence. What the hiring manager will see and reject.]
> **Source of gap:** [Resume says X, but JD requires Y.]
> **Why it matters:** [One sentence — why this gap looks disqualifying at first glance.]

### Section 2 — The Defense

Three to four arguments. Each argument has a bold header and 1-3 sentences of evidence. Every claim traced to source material.

**Argument 1: [Reframe — what the reviewer is missing]**
- [Evidence from resume or call notes that shows the gap is narrower than it looks]
- [Source: resume line / call quote]

**Argument 2: [Transferable strength]**
- [Evidence of comparable scope, environment, or outcome in a different context]
- [Source: resume line / call quote]

**Argument 3: [Specific match to this JD]**
- [Evidence that directly aligns with a requirement, even if the candidate's title/industry doesn't scream it]
- [Source: resume line / call quote]

**Argument 4: [Character / drive / intangibles — only if supported]**
- [Call notes or resume pattern that signals hunger, growth, resilience]
- [Source: call quote or tenure pattern]

### Section 3 — Remaining Risks

Honest risks that survive the defense:

- [Risk 1 — real, not manufactured]
- [Risk 2 — only if distinct and genuine]

### Section 4 — Bottom Line

> **Verdict:** SUBMIT / CONDITIONAL / DO NOT DEFEND
> **One-liner:** [Why the interview is worth the client's time despite the objection.]

If DO NOT DEFEND — stop entirely. Do not offer to continue to Mode 2 or 3.

## MODE 2 — Submission Email (Defense Framing)

Only run if Ja asked for it. Mirrors the vet skill's MODE 2 format but with optional
defense framing woven into the Profile Summary and Additional Info section.

**Rules:**
- Source only from resume, JD, and call notes
- Never invent, assume, or include anything not confirmed in the source material
- Only include field lines that have confirmed data — skip lines with nothing to say
- Bold labels before the colon, and key proof points inside bullets only
- Do not bold full sentences
- Profile Summary bullets: include only what's genuinely supported — 2 minimum, 4 maximum

---

Subject: New Candidate Submission - [Role] - [Candidate Name] - [Client] - [Location]

Hi team,

@[Configured Account Manager] I would like to present [Candidate Name] for the [Role] opportunity with [Client].

**Title:** [Current title or best-fit title — if the title undersells, add a reframe in brackets, e.g. "Maintenance Technician (effectively led the maintenance function across 3 shifts)"]

**Location:** [City, Province] | [commute or relocation note only if relevant]

**Current Company:** [Include only if it adds context — skip if it reads better in the summary]

**Compensation Target:** [e.g. Currently at $X | Targeting $Y — only if both are confirmed]

**Interview Availability:** [Only if confirmed]

**Start Date / Notice Period:** [Only if confirmed]

**Reason for Exploring:** [Factual — never invented]

**Profile Summary:**

[2 sentences max. 3 only if genuinely needed. Why this person is worth reviewing for this role specifically. Address the elephant in the room head-on if there is one. Do not repeat the resume. Do not preview the bullets below.]

- [Most important fit reason — **bold the proof point**]
- [Industry, plant, or environment match — **bold it**]
- [Technical, systems, equipment, or process match — **bold it**]
- [Leadership, ownership, or scope — **bold it** — only if supported]

**Additional Info:**

[Optional. Only if the defense needs a paragraph — addresses the gap directly with the candidate's own words or context. Keep it tight. Quote the candidate if it helps. Example: "He was upfront that his title was 'Technician' but he was the senior guy on site — running the department when his manager travelled, owning the budget, and managing the contractor relationships. Those are his words." If there's nothing real to add, skip this section entirely.]

CV attached.

Stop after the email. Do not produce the resume reframe unless Ja asks.

## MODE 3 — Resume Reframe

Only run if Ja asked for it. Text only. No markdown. No HTML. No symbols or decorative characters in headers.

The goal: tighten language, reframe underselling titles/descriptions, and clarify scope — without adding any new facts not on the original resume.

Name
[Full name]

Summary
[2-3 sentences. Current professional identity, depth of experience, environments worked in. Reframe if the candidate's own summary undersells their actual scope — but only what the resume supports.]

Skills
[One skill per line. Only skills evidenced on the resume. Do not add skills from the JD.]

Experience

[Reframed Job Title — only if the original title undersells and the resume supports a more accurate one; otherwise keep original]
[Company Name] | [City, Province] | [Month YYYY – Month YYYY or Present]
- [Rewritten bullet — tighter and clearer than original, scope-first. Never invented. ]
- [Minimum 3 bullets per role. 4-5 for primary/most relevant roles.]
- [If resume only has 1-2 weak bullets for a role, expand using context already on the resume — do not add new facts]
- [Where the resume buries scope (e.g. "assisted with" → rewrite to reflect actual ownership if the resume supports it)]

[Repeat for each role in reverse chronological order]

Education
[Degree or Diploma]
[Institution] | [City, Province] | [Year]

Certifications
[Certification Name] | [Issuing Body] | [Year if available]
[If no year on resume, omit the year — do not guess]

---

**Rules:**
- Do not copy bullets verbatim — rewrite for clarity without adding new facts
- Minimum 3 bullets per role, 4-5 for the most relevant roles
- Do not include contact information
- Omit any section that has nothing evidenced
- Do not add skills, tools, or certifications not on the resume
- Title reframes must be noted with a comment: [reframed from "X" — resume supports scope]

## Full Package Flow

If Ja asked for everything:

1. Run Mode 1. Output defense brief. Stop and confirm: **"Defense done. Want me to write the submission now?"**
2. On yes — run Mode 2. Output submission email. Stop and confirm: **"Submission written. Want the resume reframe too?"**
3. On yes — run Mode 3.

If Mode 1 returns DO NOT DEFEND — stop entirely. Do not offer to continue to Mode 2 or 3.

---

## Non-Negotiables

- Never fabricate titles, companies, tools, scope, certs, achievements, or compensation
- Never include a field line with no confirmed data behind it
- Never bold full sentences — labels and proof points only
- Never add headings not in the format above
- Never auto-proceed to the next mode
- Never force a defense that cannot be made honestly
- Never add a number that was not stated — no invented percentages, dollar figures, or head counts
- Every claim must be traceable to a specific source (resume line, call quote, JD requirement)
