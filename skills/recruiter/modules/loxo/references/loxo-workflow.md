## Workflow Model

Loxo's workflow is an end-to-end recruiting operating model:

1. Add or manage the job order.
2. Build/search the candidate pool.
3. Screen and organize people.
4. Move candidates through job pipeline stages.
5. Add notes, intake context, and status updates.
6. Submit candidates.
7. Coordinate interviews/offers.
8. Track placement and reporting.

The workflow is meant to be repeatable, visible, and scalable, so Ja's AI agents should use the same fields, tags, and notes every time.

## Jobs

Use jobs as the operating surface for active orders.

Recommended Loxo-ready job-order fields for Ja:

- Job title
- Client/company
- Location
- Work model
- Compensation range
- Must-have skills
- Nice-to-have skills
- Interview process
- Urgency/priority
- Owner/recruiter
- Notes from intake

When an AI is unsure whether work belongs in a job, company, deal, or list, it should say so and ask for the target surface.

## People: Candidate vs Contact

Use the correct person type:

- `Candidate`: someone Ja may place.
- `Contact`: client-side person, hiring manager, HR, decision-maker, or BD prospect.

Do not import hiring managers as candidates.

## CSV Import

Use for batches of candidates or contacts.

Official flow:

1. Open People or open a Job in Loxo.
2. Click the drop-down arrow beside `Add People`.
3. Import CSV.
4. Select the CSV file from the computer.
5. Choose the rows/fields to import.
6. Map every selected field to a Loxo destination field.
7. Select person type: Candidates or Contacts.
8. Optionally add to a Job Pipeline.
9. Optionally add to a List.
10. Submit; Loxo sends email notification after import.

CSV constraints from the article:

- Keep the file at 10,000 or fewer records/cells.
- Individual cells have a 2,800-character limit.
- Do not include pictures or logos.
- Row 1 should be headers only.
- No empty rows or columns.
- One tab only.
- File must be `.csv`.
- Loxo recommends 500 people/companies per CSV at a time and testing 5-10 rows first.
- Fields map 1:1 only; do not map multiple source fields to the same Loxo destination.

Recommended import columns:

```csv
First Name,Last Name,Full Name,Title,Company,Location,LinkedIn,Email,Phone,Tags,Notes
```

For Ja contact pooling, keep tags and notes in the CSV when possible.

## Tags

Tags are retrieval and segmentation infrastructure. Use consistent names; avoid one-off spellings.

Useful Ja tag examples:

- `Target Account`
- `Quality Hiring`
- `Synthetic Campaign A`
- `Synthetic Campaign B`
- `MPC`
- `BD Prospect`
- `Client Contact`
- `Do Not Contact`

Known tag operations from gathered notes:

- Add tags from a person profile by using the tags area.
- Bulk tag from People by selecting records, clicking Edit, choosing Tags, then Add or Replace.
- Admin tag management lives under settings.
- Prior notes captured Boolean-style syntax such as `tag_names:(example-client)` and `NOT tag_names:(excluded)`.
- Person tags do not apply to profiles within Jobs or Job stages; they apply to the person record.
- Bulk tag actions must select from existing tags.

Verify exact live syntax before instructing Ja to paste a search string.

## Intake Notes

Intake notes should preserve recruiter-critical call facts and uncertainty.

Use for:

- candidate compensation
- work status
- relocation/commute
- availability
- start date
- reason for leaving
- motivations
- restrictions
- verified technical fit
- risks or contradictions

Official article details:

- Intake Notes are person-specific, independent of jobs, searchable, and used for master notes.
- Open a Person Profile from People, Job Pipeline, or report.
- Click `Intake` on the right-hand side of the profile.
- Add ad hoc notes, fill a form, or add a Person Notes Template.
- Create templates under `Settings > Templates`, then `Person note`, then `+Add`.
- Note templates have a 2,048-character limit.

Person-note templates can be created in templates/settings areas. Keep templates short and fielded so they are reusable.

## Candidate Submission

Official Submission Summary pattern:

1. Open the relevant job pipeline.
2. Select candidate(s).
3. Click `Submit Candidates` above the pipeline.
4. Select what candidate information should be shared.
5. Save selections as defaults if desired.
6. Click Next.
7. Write a Submission Summary or use the Submittal Agent `Write with AI`.
8. Include Intake Notes only if they are appropriate to share externally.
9. Move through additional selected candidates.
10. Continue to the file/submission step.
