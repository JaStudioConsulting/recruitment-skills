# Submission Format

## Goal

Enable a hiring manager to make a yes/no decision in under 60 seconds using only high-signal facts.

## Fixed Snapshot Template

Use this exact structure:

```text
Subject: Client - New Candidate - <Role> - <Candidate Location>

Contact: <phone> | <email>
Name:
Title:
Compensation Target:
Target Roles:
Location:
Work Logistics:
Reason for Leaving:
Availability:

Profile Summary (max 2-3 sentences)
- Sentence 1: role + years + environment
- Sentence 2: execution focus
- Sentence 3: top 1-2 JD matches only

Key Strengths (max 3-4 bullets)
- Strength 1: direct JD must-have match
- Strength 2: direct JD must-have match
- Strength 3: risk reducer (systems/compliance/stakeholder management)
- Strength 4 (optional): adjacent role flexibility
```

## Fact Integrity Rules

- Never assert compensation, travel, relocation, visa/citizenship, certifications, or metrics unless explicit in source material.
- If inferred, omit or label as likely only when candidate-confirmed.
- Do not claim exact percent improvements without direct evidence.

## Tightness Rules

- Remove filler and unverifiable adjectives.
- Prefer concrete scope words when metrics are unavailable.
- Prioritize relevance over completeness.

## QC Checklist

1. Can a manager decide fit in under 60 seconds?
2. Are all claims source-backed?
3. Are top JD pain points addressed?
4. Are logistics and compensation alignment stated or intentionally blank?
