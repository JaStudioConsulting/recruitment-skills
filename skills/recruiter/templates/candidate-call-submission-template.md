# TTTG Candidate Call - Submission Intake Template

Copy this file per call, fill it during or right after the candidate call. Anything left blank stays blank. Start every artifact through `$recruiter`; internal capability names are not standalone entrypoints.

Rules baked in: real figures only, short answers. No em dashes, no tildes, no semicolons, no double hyphens. No spaces around slashes (CNC/manual, not CNC / manual). If a field was not covered on the call, leave it blank.

---

## Send Checklist (Claude runs this, listed so nothing drifts)

- Subject, Named: `New Candidate Submission - [Role] - [Name] - [Client] - [City, ON]`
- Subject, MPC: `MPC - New Candidate Submission - [Title] - [Name] - [City, ON]`
- Named: use host-configured account-manager and optional internal-team addresses. MPC: use only the configured internal-team mailbox.
- ONE Gmail draft, never sent, Ja reviews.
- Body ends `CV attached.` on its own line, no typed signature.
- MPC to the team attaches the NAMED resume. Blinded MPC PDF is only for external client sends.
- Blinded PDF passes the anonymity gate: no name, contact, or real employer in text, filename, or metadata. Long title in the name slot renders at 15pt using the builder's name-size option.
